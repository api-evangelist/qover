# Qover

> Qover is a Brussels-based insurtech providing an API-first embedded insurance orchestration platform used across 32 European countries. Brands, fintechs and insurers configure and distribute insurance products (travel, mobility, bike, purchase protection, accident, property) and run the full lifecycle from policy configuration and issuance through AI-assisted claims and multilingual customer care. Qover exposes REST APIs (Claims, Policy, Document Asset Management) secured with API keys, with a sandbox environment and configurable webhooks.

## APIs

- [Qover Embedded Insurance API](https://docs.qover.com/): Claims API, Policy API and Document Asset Management API. API-key auth (header), URI-path versioning (v1), sandbox base https://api.sbx.qover.io.
